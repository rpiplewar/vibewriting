# Decision memo writing

## Reference documents (read before drafting)

1. Decision framework: `${CLAUDE_PLUGIN_ROOT}/frameworks/effective-decision-making-framework.md`
2. Bias guard: `${CLAUDE_PLUGIN_ROOT}/frameworks/bias_checklist_munger.md` — check the recommendation against these biases.

## Templates

- Output structure: `${CLAUDE_PLUGIN_ROOT}/templates/decision-memo-template.md`
- Planning / working memory: `${CLAUDE_PLUGIN_ROOT}/templates/memo-task-plan-template.md`

## Process

1. Identify decision type, scope, stakeholders, and time sensitivity.
2. Gather the required information; flag gaps explicitly.
3. Develop options with weighted decision criteria.
4. Run each option and the leading recommendation through Munger's bias checklist.
5. Draft: executive summary → context → options analysis → recommendation → action items.

Follow the overall [vibewriting-method] process, including keeping a `.plan` working-memory file.
